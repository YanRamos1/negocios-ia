# Precificação MEI / artesão

Preço de venda a partir de custo, horas, taxa de cartão/marketplace e margem.

- **Público:** artesão, confeiteiro e MEI que vende no precinho e não sabe o lucro.
- **Monetização:** funil direto para a planilha de precificação.
- **Escopo mínimo:** custo de material + mão de obra + custo fixo rateado + taxas + margem desejada.
- **Próximo passo:** definir o modelo de custo e o rateio de custo fixo.
