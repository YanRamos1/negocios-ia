# Rescisão trabalhista

Verbas rescisórias por tipo de desligamento: saldo de salário, aviso, férias,
13º e FGTS com multa.

- **Público:** trabalhador demitido conferindo o valor a receber.
- **Monetização:** afiliado de advocacia trabalhista e contabilidade.
- **Escopo mínimo:** sem justa causa, pedido de demissão, justa causa, acordo, término de contrato.
- **Próximo passo:** montar matriz de regras por tipo de desligamento com casos de teste.
