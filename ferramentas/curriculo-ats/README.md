# Currículo ATS

Gerador de currículo em PDF otimizado para leitura por ATS.

- **Público:** candidato que envia currículo e não recebe resposta.
- **Monetização:** versão pro (múltiplas versões, carta de apresentação, revisão).
- **Escopo mínimo:** entrada guiada, saída em PDF de coluna única, palavras-chave da vaga, sem tabela/ícone que quebra parser.
- **Próximo passo:** escolher gerador de PDF e desenhar o layout ATS-safe.
