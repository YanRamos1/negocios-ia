# ferramentas

Sites com SEO: calculadoras e geradores. Cada pasta é um projeto independente.

Padrão de cada ferramenta:

1. Cálculo puro em módulo isolado (`calc.js` / `calc.py`) com teste.
2. Página estática indexável, resultado renderizado sem exigir login.
3. Resultado compartilhável + captura de e-mail opcional (isca para o produto).
4. Bloco de afiliado/lead só depois do resultado (não atrapalha a resposta).

Projetos: `clt-pj`, `custo-importacao`, `taxa-marketplace`, `precificacao-mei`,
`rescisao`, `curriculo-ats`, `plano-aula-bncc`, `solar-payback`.
