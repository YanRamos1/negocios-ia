# Custo de importação

Custo final de uma compra internacional: imposto de importação, ICMS, taxas e
regras de remessa.

- **Público:** comprador de site internacional querendo saber "quanto vou pagar de verdade".
- **Monetização:** afiliado de redirecionador de compras e cupom.
- **Escopo mínimo:** faixas de valor, alíquota estadual por UF, frete e seguro no cálculo.
- **Próximo passo:** mapear alíquotas e faixas vigentes; modelar entradas (valor, frete, UF, categoria).
