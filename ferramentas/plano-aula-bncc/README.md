# Plano de aula BNCC

Gerador de plano de aula alinhado à BNCC por ano, disciplina e habilidade.

- **Público:** professor da rede pública montando plano semanal.
- **Monetização:** assinatura barata; bundle com materiais complementares.
- **Escopo mínimo:** seleção de habilidade, objetivos, metodologia, avaliação, exportação em PDF/DOCX.
- **Próximo passo:** validar os campos exigidos pela coordenação e o formato de exportação.
