# Financeiro MEI

Controle financeiro para MEI: separação PF/PJ, apuração do DAS, acompanhamento
do limite de faturamento e reserva de imposto.

- **Preço alvo:** R$27–47.
- **Abas:** lançamentos, resumo mensal, DAS, limite anual, reserva de imposto.
- **Próximo passo:** definir abas, travas de fórmula e a versão gratuita (isca).
