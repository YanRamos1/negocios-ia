# produtos

Materiais empacotados para venda direta (Kiwify/Hotmart/Gumroad).

- `planilhas/` — planilhas de gestão (financeiro, estoque, precificação, e-commerce).
- `notion-templates/` — templates de Notion.

Regra: cada produto tem versão gratuita (isca) e completa (paga). O arquivo
entregue é gerado por script sempre que possível, para não manter duas cópias
divergentes.
